# Data-Analysis-Olympics-History-dataset-2016

We shall download the 120 years of Olympics History dataset from Kaggle. This way instead of using cooked up data, we shall use real data to write our SQL Queries. By having real data, it will be much easier for us to understand the data and then relate to it and write different types of queries over it.
